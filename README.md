# Simple Interest Calculator

A simple interest calculator written in Bash that calculates the simple interest based on the given principal amount, annual rate of interest, and time period in years.

## Features
- Prompts user for principal amount, annual interest rate, and time period.
- Computes simple interest using the standard formula.
- Displays the computed interest clearly.

## Input Parameters
- **Principal (P)**: The initial sum of money.
- **Annual Rate of Interest (R)**: The percentage interest rate per year.
- **Time Period (T)**: The time duration in years.

## Formula
```
SI = (P x R x T) / 100
```

## How to Run
Run the script using Bash:
```bash
bash simple-interest.sh
```
Or make it executable and execute directly:
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
